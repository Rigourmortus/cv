# CV Repository

## MindBridge mobile app (iOS + Android)

I added a cross-platform React Native (Expo) app in `mobile-app/` focused on connecting clients with mental health therapists.

### Features
- Browse licensed therapists with specialty filters.
- View full therapist profile details.
- Book a session (video, voice, or in-person).
- Persist booked appointments locally with AsyncStorage.
- Review upcoming sessions in an appointments screen.

### Run the app
```bash
cd mobile-app
npm install
npm run start
```

Then press `i` for iOS simulator or `a` for Android emulator in the Expo CLI.
